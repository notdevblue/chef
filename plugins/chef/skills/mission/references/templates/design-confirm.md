새 확인 A는 [schema 2 초안](design-confirm.json)에서 시작한다. 제목 80자·항목명 40자는 입력 제한이다. 산문 160자·항목 합계 320자는 작성 진단이며 불릿 분할을 요구하는 차단선이 아니다. 일반 설명은 paragraph, 승인 조건은 rules, 실제 처리 순서는 steps로 작성한다. 최신 명세를 검토한 뒤 `presentation: "decision"`으로 현재 질문을 먼저 표시한다.

이 양식은 정형 질문 원본에 쓸 산문과 최신 승인 대상의 표시 순서를 보여 준다. 상태 머리글·미답 문항·전체 이력 링크는 생성 문서에 맡긴다. 현재 선택·유효 조건은 답변된 옵션과 정형 blocks에 반영하며, 다른 절에서 명확하면 별도 요약을 만들지 않는다. 과거 설계·답 원문은 누적하지 않는다.
