# Hermes adapter-init

[공통 절차](../../../shared/skills/adapter-init.md)를 먼저 읽고 따른다.

런타임은 hermes다. 프로젝트 설정은 `.hermes/orchestrator/adapter.json`, 런타임 덮어쓰기는 `runtimes.hermes`, PC별 값은 제외된 local.json에 둔다. 프로젝트별 실행 절차는 개인 어댑터에 유지한다.
