# Hermes doctor

[공통 절차](../../../shared/skills/doctor.md)를 먼저 읽고 따른다.

공유 doctor 명령에 `--runtime hermes`를 지정한다. 현재 프로젝트 또는 선택한 슬롯에서 `chef_worker_status`로 실행 방식과 지원 역할을 확인한다. Codex 훅 신뢰와 Hermes 자식 도구 설정은 [설치 안내](../../README.md)를 확인한다. 실제 파견이 완료되어야 모델 실행을 확인할 수 있다.
