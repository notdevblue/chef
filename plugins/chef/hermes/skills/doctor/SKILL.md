# Hermes doctor

[공통 절차](../../../shared/skills/doctor.md)를 먼저 읽고 따른다.

공유 doctor 명령에 `--runtime hermes`를 지정한다. 네이티브 플러그인의 활성 상태와 Codex 구독 로그인·신뢰된 Chef 훅은 [설치 안내](../../README.md)를 함께 확인한다. doctor 출력만으로 실제 모델 작업 완료를 판단하지 않는다.
